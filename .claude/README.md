# Project Configuration for Claude Code

This directory contains configuration settings for Claude Code AI assistant.

## Quick Start

Before any coding task, read the workspace behavioral guidelines in `CLAUDE.md` at the project root.

## Configuration Notes

- **Always Apply Rules**: The `karpathy-guidelines.mdc` rule in `.cursor/rules/` is configured with `alwaysApply: true`
- **Skill Discovery**: Skills are auto-discovered from `.cursor/skills/` directory
- **Behavioral Guidelines**: See `.cursor/rules/karpathy-guidelines.mdc` for coding guidelines
