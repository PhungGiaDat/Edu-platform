## Deployment Commands

### Local Development
```bash
# Start all services
docker-compose up -d

# View logs
docker-compose logs -f

# Stop
docker-compose down
```

### Docker Production
```bash
# Build and start
docker-compose --profile production up -d --build

# Scale backend
docker-compose up -d --scale backend=3
```

### Manual Deploy
```bash
# Frontend (Vercel)
cd frontend-web && vercel deploy --prod

# Backend (Render)
# Set env vars in Render dashboard and deploy
```
