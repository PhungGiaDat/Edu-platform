# Fix Report

**Date:** 2026-08-25
**Source:** User UI Request
**Files Changed:** `frontend/src/components/Sidebar.tsx`

## Input Summary

**Issue:** Two collapsed sidebar buttons (`My Pet`, `Stickers`) were not using the shared semantic class `learner-sidebar__collapsed-link`, causing inconsistent hover/focus transitions compared to collapsed nav links (`Learn`, `Path`, `AR`, `Cards`, `Profile`).

## Fixes Implemented

### Collapsed Pet/Stickers buttons — use shared semantic class + consistent z-index

**File:** `frontend/src/components/Sidebar.tsx`
**Lines:** 507, 510

| Button | Before | After |
|--------|--------|-------|
| My Pet | `flex min-h-[58px] w-full...` | `learner-sidebar__collapsed-link relative z-[1] flex min-h-[58px] w-full...` |
| Stickers | `flex min-h-[58px] w-full...` | `learner-sidebar__collapsed-link relative z-[1] flex min-h-[58px] w-full...` |

**Fix applied:**

- Added `learner-sidebar__collapsed-link` class — picks up CSS transition rules for `color`, `background-color`, `transform` (lines 193-201 of `sidebar.css`)
- Added `relative z-[1]` — consistent stacking context matching nav links
- Active state uses `learner-sidebar__collapsed-link--active` modifier class, preserving feature-specific colors (`#FF9F9F` for Pet, `#FFD84D` for Stickers) via inline override, consistent with how nav links handle active state
- Added `z-[2]` on active state to match nav links' active z-index boost

**Active-state colors preserved per feature:**
- Pet: `bg-[#FF9F9F]` / `text-white` / `shadow-[0_4px_0_#D97070]`
- Stickers: `bg-[#FFD84D]` / `text-slate-800` / `shadow-[0_4px_0_#E8B800]`
