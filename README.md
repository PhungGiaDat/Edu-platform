# Edu-platform

## Introduction
Edu-platform is a full-stack, gamified English-learning platform built for kids. It combines AR practice, interactive courses, flashcards, and progress analytics, plus rewards such as pets, badges, and streaks to drive engagement. The web app emphasizes a mobile-first claymorphic UI with responsive layouts and reusable components, making it easy for developers to extend features while keeping the experience playful and consistent.
