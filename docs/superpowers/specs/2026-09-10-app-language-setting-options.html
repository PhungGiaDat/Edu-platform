3 · Ba approaches (best-of-n)

A — Dict consolidation

Giữ dict 369 keys làm nguồn duy nhất learner; migrate GamesPage + games pages + Profile sang useLocale; thêm settings UI ở Profile.

⏱ Effort: ~7 files🎯 Risk: THẤP⚠️ 2 hệ thống song song vĩnh viễn

B — react-i18next full consolidation

Chuyển 369 keys → JSON, 16 files useLocale → useTranslation, 1 hệ thống duy nhất.

⏱ Effort: LỚN🎯 Risk: CAO trước graduation✅ Sạch nhất dài hạn

C — Hybrid bridge RECOMMENDED

Scope migrate = A, NHƯNG thêm bridge: t(key) fallback i18n.t(key) khi thiếu → keys mới viết vào JSON (prefix learner.*), keys cũ giữ dict. Path dần dần về B không big-bang. Setting UI ở Profile (mọi user).

⏱ Effort: ≈ A + 10 dòng bridge🎯 Risk: THẤP🧭 Có exit-path về B

4 · Polish tuỳ chọn (nếu muốn "hay hơn nữa" — đều trên i18next, không đổi library)

Không cần thêm package

  • Type-safe keys: augment CustomTypeOptions resources → autocomplete + chống sai key
  • Plural rules en (_one/_other) — vi không cần nhưng sẵn sàng
  • Language names native trong switcher: "Tiếng Việt / English"
  • document.documentElement.lang — đã có sẵn trong LocaleProvider

Cần thêm plugin nhỏ (tuỳ chọn)

  • i18next-browser-languagedetector — thay hand-rolled detect (hiện tại đã hoạt động tốt → ưu tiên THẤP)
  • i18next-http-backend lazy-load locale JSON — chỉ đáng khi JSON phình (hiện 2 locales nhỏ → KHÔNG cần)

5 · Grill-me — 7 câu sắc (kèm câu trả lời đề xuất)

Q1. "Toàn bộ app" = đến đâu?
→ P0: Profile + GamesPage + games pages + settings card. P1: còn lại dần dần (mỗi lần đụng page thì chuyển keys sang JSON). Dịch 30+ page một nhịp là không thực tế.
Q2. Fallback copy GamesPage khi catalog API fail — locale=en?
→ Mọi copy fallback đi qua t() — dict en đã có key.
Q3. Test impact?
→ gamesPageCatalog test phải wrap LocaleProvider (pattern đã có ở CourseDetail/CourseList tests). Chấp nhận.
Q4. Keys mới để JSON nào?
→ Trong admin.json prefix learner.* — 1 file/locale giảm churn; hy sinh namespace sạch lấy tốc độ.
Q5. profile.* keys thêm hôm qua?
→ Xoá khỏi admin.json, chuyển sang dict LocaleContext — Profile chỉ dùng 1 nguồn.
Q6. Auto-detect browser?
→ Giữ nguyên (có cờ auto-detected; user chọn tay thì ngừng auto).
Q7. Persistence?
→ localStorage edu-platform-locale — 1 key dùng chung, không migrate storage.

6 · Scope P0 nếu duyệt C

  • Bridge: LocaleContext.t() fallback i18n.t() (~10 dòng) — giữ các edits interpolation hiện có
  • Language settings card ở Profile (segmented Tiếng Việt / English, clay style, mọi user thấy, gọi setLocale)
