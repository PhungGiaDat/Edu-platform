3b · Bảng map preset Độ khó → config kỹ thuật MỚI THEO FEEDBACK

Giáo viên chỉ chạm vào Dễ/Vừa/Khó. Preset là frontend-only: khi bấm Lưu, FE map ra config JSONB đúng contract API (backend không đổi). Mục "Nâng cao" ghi đè preset khi được chỉnh.

Mapping (FE transform on save)
🌧 Bắt chữ rơi — Dễ: fall_speed 0.8 · spawn 1200ms · Vừa: 1.2 · 800 · Khó: 1.6 · 500
🧩 Ghép cặp — Dễ: pair_count 4 · timer 120s · Vừa: 6 · 90s · Khó: 8 · 60s
🃏 Lật thẻ nhớ — Dễ: pair_count 4 · flip 1500ms · Vừa: 6 · 1000ms · Khó: 8 · 600ms
🔤 Xếp chữ — Dễ: word_count 5 · hint 3 · Vừa: 8 · 2 · Khó: 10 · 1
Preset mặc định khi tạo mới = ⚡ Vừa. Helper text dưới preset diễn giải bằng lời thường ("từ rơi nhanh hơn, số cặp nhiều hơn…").
Quy tắc upload (áp dụng ui-ux-pro-max)
  • Dropzone kéo-thả + bấm-chọn — không bao giờ để input file trần
  • Preview thumbnail ngay sau chọn + progress + "Đã tải lên ✓"
  • Nút Thay ảnh / Xoá bằng SVG icon (Lucide) + title tooltip
  • Nén tự động client-side trước khi upload Supabase
  • Không dùng emoji làm icon chức năng trong UI thật (mockup chỉ minh hoạ)
  • Cursor-pointer + focus-visible cho mọi vùng bấm được

Topics & games đọc từ GET /games/catalog (chỉ game đã XB). API fail → fallback đúng bản hardcode hiện tại, không bao giờ trắng trang. Copy trần lượt chơi derive từ catalog.
Bạn đang duyệt những gì — checklist
  • Style Clay Editorial giữ nguyên — chỉ thêm 2 trang admin mới theo đúng tokens
  • GameManager + GameEditor: 4 engine (ghép cặp / bắt chữ rơi / xếp chữ / lật thẻ). Coloring không admin-editable ở v1
  • Độ khó = preset Dễ/Vừa/Khó (FE map ra config khi lưu); số kỹ thuật ẩn trong "Nâng cao" collapsible — không nhét số ms/× vào mặt giáo viên
  • Upload = dropzone kéo-thả + preview + nút thay/xoá (SVG icon, nén tự động, progress) — không input file trần
  • Khung "Xem trước" mini trong GameEditor (mô phỏng màn chơi từ dữ liệu chủ đề)
  • Topic là dữ liệu (bảng mới + seed 4 topic cũ giữ slug)
  • Fix course: route chi tiết, overlay /admin, role notice, banner lỗi, media persist, update không 500, is_template, learning-goals body
  • GamesPage động + fallback hardcode
  • XP không đổi — backend authoritative, idempotent
