**useARSession update:**

- onComboComplete fires inside `handleUnityEvent` for `onComboComplete` Unity event
- Uses ref pattern to avoid stale closure in event handler

**ARScreen XP wiring:**
```tsx
useARSession(undefined, undefined, {
  onComboComplete: async (xpAwarded, comboId) => {
    // Idempotent XP via /gamification/xp-event
    await api.post('/gamification/xp-event', {
      action: 'combo_complete',
      event_id: `combo_${comboId}_${Date.now()}`,
      metadata: { comboId, xpAwarded },
    });
    // Show reward celebration overlay
    setRewardCelebration({ xpAwarded, comboDescription, streakCount });
  }
});
```
