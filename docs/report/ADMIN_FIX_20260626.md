## Fixes Implemented

### ISSUE-001: Flashcard Parameter Naming Consistency ✅

**Files Modified:**
- `backend/api/admin.py` (lines 346, 368)
- `frontend-web/src/services/adminApi.ts` (lines 214-237)

**Fix Applied:**
Updated backend routes to use `qrId` (camelCase) instead of `qr_id` (snake_case) to match frontend convention.

**Changes:**

`backend/api/admin.py`:
```python
# Before:
@router.put("/flashcards/cards/{qr_id}", response_model=AdminFlashcardResponse)
async def update_flashcard(qr_id: str, ...)
@router.delete("/flashcards/cards/{qr_id}", status_code=status.HTTP_204_NO_CONTENT)
async def delete_flashcard(qr_id: str, ...)

# After:
@router.put("/flashcards/cards/{qrId}", response_model=AdminFlashcardResponse)
async def update_flashcard(qrId: str, ...)
@router.delete("/flashcards/cards/{qrId}", status_code=status.HTTP_204_NO_CONTENT)
async def delete_flashcard(qrId: str, ...)
```

**Status:** ✅ Fixed - Backend now uses consistent `qrId` naming

### ISSUE-002: Learning Goal POST Body Parameter ✅

**File Modified:**
- `frontend-web/src/services/adminApi.ts` (lines 307-322)

**Fix Applied:**
Updated `setLearningGoal` to send `user_id` in the request body instead of as a query parameter.

**Changes:**

`frontend-web/src/services/adminApi.ts`:
```typescript
// Before:
const response = await apiClient.post(
  `${ADMIN_BASE_URL}/learning-goals`,
  data,
  { params: { user_id: userId } }
);

// After:
const payload = { ...data, user_id: userId };
const response = await apiClient.post(
  `${ADMIN_BASE_URL}/learning-goals`,
  payload
);
```

**Status:** ✅ Fixed - Frontend now sends `user_id` in request body
