# Code and Security Review

Date: 2026-07-14

Scope: admin auth, dynamic profile, responsive navigation, tracker/icons, course Unicode repair, Lexi

## Result

Approved for staging verification. No unresolved critical or high findings were found.

## Review checklist

- Access control: `/api/v1/profile/me` derives identity exclusively from `get_current_user`; no client user ID is accepted, preventing IDOR.
- Admin UI authorization: browser state is hydrated from `/api/v1/auth/me`; backend admin routes continue to enforce teacher/admin/superuser independently.
- Sensitive data: the hardcoded admin seeder was replaced with environment-only, dry-run-first provisioning. The disclosed password was not used, logged, or committed.
- Debug exposure: `/debug/admin-hash` was removed because it exposed password-hash material and exception traces.
- Failure isolation: optional Profile sources add `meta.partial_sections`; they do not erase identity or core defaults.
- Data safety: Unicode migration targets three fixed course IDs, updates only suspicious string paths, backs up each full source document, defaults to dry run, requires an explicit confirmation token, and converges idempotently.
- UI accessibility: labeled mobile navigation, 44 px minimum targets, safe-area spacing, focus trap/return, Escape/backdrop close, `aria-expanded`, progress semantics and reduced-motion handling are present.
- Styling isolation: tracker sizing is component-scoped; shared global clay utilities were not changed.

## Findings fixed during review

1. Profile unit tests loaded the entire eager `services` package and hung on unrelated integrations. The service dependencies were made lazy and the isolated test module loader now avoids that infrastructure graph.
2. Sidebar route effect received an unstable callback. Layout now memoizes the setter.
3. Mobile More focus return captured a mutable ref in cleanup. It now captures the trigger element when the dialog opens.
4. New Sidebar `any` usages were replaced with unknown-safe parsing.

## Non-blocking inherited findings

- Vite reports existing Three.js export/dynamic-import warnings and chunks above 500 kB.
- The existing dependency set reports audit findings; dependency upgrades were excluded because they require a separate regression effort.
- Visual viewport inspection still needs a staging/browser pass at the documented sizes before production deployment.
