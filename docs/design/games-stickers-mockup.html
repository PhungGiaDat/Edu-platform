Three.js — đã có sẵn trong repo

Sân chơi đất nặn 3D — demo chạy thật dưới đây

Kéo để xoay · chạm để bung confetti clay. Toàn bộ vật thể dựng bằng primitive (sphere/torus/star) — chính là "clay blob" của brand. Bản production: mỗi game một scene nhẹ, lazy-load, dpr cap.

view_in_arClayScene3D · demo
Kéo để xoay · Chạm để nổ confetti

WebGL không khả dụng trong trình duyệt này — production sẽ fallback về bản 2D SVG (game vẫn chơi được đầy đủ).

Đã có sẵn — 0 npm mới
  • three ^0.158.0 + @types/three đã trong frontend/package.json (stack AR đang dùng)
  • GLB kho sẵn dùng được cho word-card 3D: apple 14KB · banana 12KB · flower 7KB · cactus 9KB · cake 71–113KB · buddy 111KB
  • Loại trừ: elephant.glb 20MB, giraffe 4MB — quá nặng mobile web (chỉ dùng khi DRACO-compress sau)
3D ở đâu — không ở đâu
  • Hub: ambient clay orbs trôi sau topic cards (depth + life)
  • DragMatch: thẻ tilt 3D theo ngón (CSS 3D) + word-card có GLB nhỏ → xoay preview mini
  • MemoryPairs: flip thẻ bằng CSS perspective; khi thắng → confetti 3D burst
  • Tô màu: canvas tô giữ SVG region-fill (mechanic 2D đúng spec); xung quanh = podium crayon 3D + celebration
  • Không 3D: chữ, palette, nút — a11y + touch-target giữ DOM thuần
Perf guardrails (mobile web)
  • Lazy-load: const THREE = await import('three') chỉ khi mở game route
  • Mỗi màn ≤ 1 canvas; DPR cap 1.5; pause khi document.hidden
  • Dispose geometry/material khi unmount; geometry+material cache dùng chung
  • prefers-reduced-motion → tắt auto-float/confetti, giữ trạng thái tĩnh đẹp
  • Fallback 2D: WebGL fail → game chạy trọn vẹn bản SVG (không bao giờ chặn bé)

notebook_entries (topic có sẵn) + SEED_VOCAB 8 từ × 4 chủ đề
↓
GET /api/v1/games/vocab?topic=animals&limit=8 — merge, trả [{word, translation_vi, image_url}]
↓
3 Games — Hub chọn topic · chơi bằng từ thật · ảnh từ /assets/game-cards/{topic}/
↓
POST /gamification/xp-event — action game_complete, event_id idempotent, backend quyết 20 XP
↓
Sticker hook — đủ 3 game/topic/ngày → random theo rarity → album + sidebar tracker cập nhật
