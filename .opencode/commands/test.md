Use the SDLC `tester` agent to run tests locally and analyze the summary report.

$ARGUMENTS

**MODE:** Apply the current mode (YOLO/INTERACTIVE).

## What to do

1. Run the existing test suite.
2. Collect results.
3. Analyze failures.
4. Present a clear summary report.
5. Hand off to `@fix` when failures are found.

**Output:** `./report/TEST_REPORT_YYYYmmdd_HHMMSS.md`
